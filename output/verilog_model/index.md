# Tutorial: verilog_model

该项目提供了一个 **PCIe 5.0 PHY (物理层)** 的*数字验证模型*。它主要由两部分构成：负责数字逻辑处理的 **原始PCS (Raw PCS)** 的RTL代码，以及模拟PHY模拟电路行为的 **PMA行为模型**。这个模型使得工程师能够在芯片实际制造之前，通过仿真来验证PHY的逻辑功能，并且支持*快速仿真模式*以显著缩短设计和验证周期。
