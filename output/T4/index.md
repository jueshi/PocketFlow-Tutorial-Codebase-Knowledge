# Tutorial: T4

这个项目提供了一个 **Python 脚本**，用于控制和测试 *Synopsys E224G* 物理层 (PHY) 芯片。
脚本的核心是一个 **设备控制器 (`E224G` 对象)**，它封装了所有与硬件交互的操作。
用户可以通过这个控制器来 **配置设备参数**、**执行误码率 (BER) 测量**、**从芯片内部 SRAM 捕获数据**，以及进行底层的 **寄存器读写**。
它还支持通过网络与后端服务进行 **远程命令执行**，以实现更复杂的控制。
