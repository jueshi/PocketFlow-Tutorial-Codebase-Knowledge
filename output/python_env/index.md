# Tutorial: python_env

这个项目是一个 *Python* 环境，用于与 **SERDES** (串行器/解串器) 硬件进行交互。
它提供了一个*图形用户界面* (GUI)，让用户可以方便地查看和修改硬件的*寄存器状态*，运行预定义的*验证脚本*来测试硬件功能，以及执行*固件更新*流程。
所有这些操作都通过一个*API客户端*与后端的硬件控制服务器进行通信。
