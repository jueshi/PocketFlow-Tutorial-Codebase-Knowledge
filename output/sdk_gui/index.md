# Tutorial: sdk_gui

这是一个 **图形用户界面 (GUI)** 应用程序，旨在帮助用户配置和测试 *SERDES PHY硬件*。
它提供了一系列配置页面，例如 *前导码、MAC和PHY设置*，允许用户调整参数并通过与后端服务器交互来应用这些配置并查看结果。
